Initiation ---------------------------------------------------------------

Simulating psychology/neurology as predictors for financial data with game theory.

We can use Brian NN/ Pandas/ Pytorch/ Sci-Kit-Learn to determine how the brain may make decisions (i.e. game theory) via neural network weights and correlate decision matrices with financial data choices.

Agentic systems, however, most likely will be a worse prediction model than a humanist method/approach. Risk/reward systems are not exactly the same as neuronal weights. We aren't given full information, but we aren't exactly given none either. Influences are inherently biases, so current media consumption, politics, news, word of mouth, etc are impossible to fully calculate but need to be considered as the main differential between agents and human neural networks. Partial (variable) influences are changing by both view, magnitude, and gate. This will be the most difficult variable in implementation, scope, and accuracy, but is also *why* the research is so interesting from financial, neurological, psychological, and general scientific perspectives.

Training financial datasets will be hard to come by, as financial data is NOT inherently bias-adverse.
